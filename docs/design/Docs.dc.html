{{r.n}}{{r.t}}

Current limits

  • GitHub only. GitLab and Bitbucket are not supported yet.
  • Python 3.10–3.13 with pytest; Node 20+ with vitest or jest.
  • Tests that need live third-party services cannot be proven in the sandbox. Use your runners and fixtures.
  • Incidents without a fix commit stay in “Awaiting fix” and are never proven by guesswork.
